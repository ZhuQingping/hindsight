# 实体与关系浏览

实体用于把涉及同一人物、组织、项目等对象的记忆联系起来。在当前工作空间打开“实体”，可以通过列表找到对象，也可以通过关系图观察实体之间的共现。

实体来自内容处理中的提取与关联。它不是控制台成员账号，也不因名称相同就获得访问权限。

## 从列表找到实体

1. 进入目标工作空间，打开“实体”，选择“列表”。
2. 如需限定资料范围，选择标签，并设置匹配任意或全部标签。
3. 查看名称、提及次数、首次出现和最近出现。
4. 点击目标行，打开实体详情。
5. 当前页没有目标时，继续翻页，或检查标签范围和来源是否已经处理完成。

标签筛选会影响当前实体范围、提及统计、时间信息及关系图，不只是隐藏几行列表。选择标签后的范围会排除不带这些匹配标签的来源。

| 字段 | 用途 |
| --- | --- |
| 名称 | 服务使用的实体名称 |
| 提及次数 | 当前范围内与实体相关的提及统计 |
| 首次出现 / 最近出现 | 了解该实体在当前资料范围内的时间跨度 |
| 实体 ID | 定位具体对象；核对问题时比只提供名称更明确 |

提及统计用于理解实体与记忆的联系，不应直接当作原文关键词出现次数或业务访问次数。

## 通过关系图观察共现

切换到“关系图”，可以看到实体节点及它们之间的连线。

| 图中元素 | 含义 |
| --- | --- |
| 节点 | 当前加载范围内的实体 |
| 连线 | 两个实体出现在同一条记忆中形成的共现关系 |
| 节点大小 | 与该实体相关的共现量 |
| 时效性颜色 | 在时间信息可用时，表示最近共现时间的相对位置 |

例如，一条记忆同时提到 Alpha 项目和 PostgreSQL，它们可能形成共现连接。这说明两者在资料中被共同提及；具体关系仍需要回到记忆查看，不能仅凭连线判断因果或隶属关系。

点击节点可以打开实体详情。关系图展示当前加载的共现范围，列表则提供分页浏览；不要把图中节点数当作整个 Bank 的实体总量。

## 查看详情与关联记忆

实体详情提供提及统计、首次出现时间、实体 ID，以及关联记忆的时间线。

1. 先核对实体名称和 ID，确认查看的是预期对象。
2. 在时间线中选择相关记忆，打开记忆详情。
3. 阅读正文及时间信息，需要上下文时继续查看来源文档或分块。
4. 发现事实不准确时，按[内容纠正流程](console.md#5-修改纠正与删除)处理相应事实或来源。

时间线基于已加载、具有可用日期的关联记忆。空时间线不一定表示实体没有内容，也可能是关联记忆缺少可绘制的日期，或当前筛选范围没有匹配项。

## 与其他关系图怎样区分

概览和“记忆”页面的关系探索以记忆为节点，实体页面的关系图以实体为节点，显示的是共现关系。它们的节点、连线与统计口径不同。

如果你想知道“哪些记忆互相关联”，从记忆视图进入；如果你想知道“某个人物、项目或组织在资料中与哪些对象一起出现”，从实体视图进入。
