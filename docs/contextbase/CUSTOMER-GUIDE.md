# ContextBase 用户指南

ContextBase 为 AI 应用和 Agent 提供长期记忆服务。你可以保存对话、资料和任务记录，在后续交互中找回相关信息，或基于已有记忆生成回答。

本指南介绍 ContextBase 的核心概念、接入方法、应用实践和控制台操作。首次使用时，可从[快速开始](user-guide/quickstart.md)了解如何获取连接信息，并完成第一次写入与查询。
