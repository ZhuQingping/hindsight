## 外部条件与确认事项

| 事项 | 需要提供或确认的内容 |
| --- | --- |
| 计算与网络 | 目标 OS、架构、规格、VPC/子网、安全组、访问方式、资源归属及回收责任 |
| 云 PostgreSQL | 版本、vector/pg_trgm/btree_gin、运行与迁移权限、TLS/CA、连接上限及网络 |
| OBS | bucket、endpoint/region、受限凭证、服务端与客户端下载网络、对象及分片清理策略 |
| 模型服务 | LLM、embedding、reranker 的实际接口、鉴权、型号/版本、维度、超时与并发限制 |
| 平台身份与网关 | 用户到实例的归属校验、登录/退出、域名/TLS、可信代理、Cookie、流式与文件限制 |
| 实例管理与管控 | 确认已有平台及 agent 的接口、机器身份、指令、心跳、结果查询和失联处理 |
| 制品与发布 | 固定源码、依赖、构建参数、制品标识、发布仓库和部署配置 |
| 运维与支持 | 日志/指标接收、实例标签、告警、日志保留、备份策略、恢复边界及问题负责人 |

实例管理与管控接口到位后，对齐实例/机器身份、资源绑定、
目标与实际版本、配置版本、操作结果及重复请求处理。
由选定的平台控制面维护生产目标状态，避免重复控制通道。
外部凭据通过约定渠道交付，文档和普通日志只保留非敏感配置及引用。

## 目标环境验证

- 从固定制品完成初始化、API/UI 启动及实例身份检查。
- 使用业务 Key 完成 Retain、确认处理完成、Recall，并检查 Worker 实际执行。
- 验证无效、过期、停用、只读和越权 Key 在 REST/MCP 及间接资源入口的行为。
- 使用独立实例交叉验证平台入口、PG、bucket 和凭据隔离。
- 验证 OBS 实际上传、下载、列表、删除、分片及签名链接兼容性，
  并检查附件、导入导出、文档/Bank 删除后的元数据与对象引用。
- 在最终网关验证登录/退出、可信代理、认证头、Cookie、MCP、
  流式响应和文件传输；API 与 MCP 地址分别交付。
- 验证目标模型的协议、功能、质量和并发限制，并测量目标规格下的运行基线。
- 验证启停、重启、配置、升级及故障处理，检查实际版本、任务结果和告警。
- 接入云资源生命周期管理时，验证申请失败、重复操作、失联和部分成功的结果。

## 数据与验收边界

释放计算和访问入口与销毁 PG/OBS 数据分开处理，资源归属和绑定可追溯。
升级前备份数据库、匹配产物、配置和秘密；应用回退须核对数据库兼容性。
已签出的下载链接按自身有效期失效；任务受理、内容入库和派生刷新分别判断。
本文不新增集群高可用、自动迁移、弹性扩缩或完整计费承诺。
