- **当前性能版真实 BGE 只完成 3/20，剩余 17 题待验**；不能用上一版 120 次真实 BGE 全量通过替代。
- 最终 v2 错误路径修补后重跑全部评分位比较，未重跑整轮 HTTP 性能和真实 BGE。
- 全仓 lint 运行后仍有既有 `api/http.py:5886` F841，不标为全仓绿色。
- 未完成生产多租户、并发写入、附件、全部请求形状、完整 SDK 黑盒验收。
- 未证明完整带模型 Recall 提速；无新准确率、Token 节省成绩。平均/P50 各下降 20% 的阶段目标未达成；3/20 题平均退化。
- 没有实现跨路并行、动态剪枝、BM25、PG 模型桥接或 PG 最终预算。
