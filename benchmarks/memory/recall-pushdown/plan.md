## 2. 当前交付门槛

1. 支持的81题由服务端store接管，每题一条候选SQL；API外层和PG内部语句分别统计。
2. 查询返回后不hydrate、不补读原文，不在错误后静默重跑原路径。
3. 原始各路名次、RRF输出、实际模型输入、业务JSON和最终reader上下文逐题保持一致。
4. BGE在PG连接释放后执行，原模型参数、评分与预算不变。
5. 不支持形状或哈希环境在查询前退出接管；数据范围错误可见，不返回近似结果。
6. 不修改原Bank，不重启或切换原8892/8891，不提交凭据、权重、向量、真实回包或动态库。

以上已在当前固定数据、请求和运行环境范围通过。全仓lint仍有原有`api/http.py` F841，不标为全仓绿色；该限制与检查日志一并记录。
